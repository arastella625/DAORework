# 0.7.0 release notes: a draft

**Not released.** A draft for the owner to edit, from `CHANGELOG.md`'s 0.7.0 section. The date is set on tag day.

## Mods that run inside the game

- **DAO Lib and mods like it now install,** with the same preview, backup and *Undo* as any other mod. They put a
  program beside the game's own, so DAORework asks first: tick *I trust this mod and where I got it*, and only then can
  you apply. The files are checked against your Library's copy and scanned again before they go in.
- **A mod says what it needs.** The controller mod needs the 4 GB patch, and its preview says when it's missing, or
  that it can't go on Steam's protected copy. DAO Lib and the controller mod conflict, and the preview links the way to
  use both.
- *Turn on selected* leaves these mods out and names them, so each one is said yes to on its own.

## Add-ins that share a file

- When two add-ins ship a file of the same name, *Check the game* says whose copy the game uses: the lower Priority,
  or the one listed first on a tie, as checked in the game.
- On Mods, each add-in shows its Priority and whether it wins or loses a shared file, and *Add-ins sharing files* shows
  only those.

How other mods are installed, backed up and undone. There is still no Linux download.
