## Pictures

The `[img]` lines in the description load the pictures from the project website,
`https://daorework.dilly-world.net/images/` ([ADR-0021](../../adr/0021-project-website.md)), so they show on Nexus
even while the GitHub repository is private.

Also upload them to the mod's **Images** tab, so they appear in its gallery: the files in
[site/public/images](../../../site/public/images), `00-cover.png` as the main image, then the screenshots in order,
each with its line from [captions.txt](captions.txt). (Or your own screenshots from a real install, which show Windows
paths, real mod names and a real antivirus result.)
