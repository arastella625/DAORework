DAORework

A mod manager, launcher and diagnostics tool for Dragon Age: Origins.

Plan first. Backup always. Roll back anything. Free, always.

Download Check your download

What it does

  • Takes over the mods you already installed by hand, without reinstalling them. Official DLC is never touched.
  • Installs mods safely. Import a .dazip, .zip, .7z or .rar, see exactly what will be copied, replaced or removed, and nothing changes until you apply it. A backup is taken first.
  • Shows conflicts. For every file two mods share, see whose copy the game uses, and reorder them.
  • Checks every mod. Your own antivirus scans it before it is kept, programs inside a mod are never installed, and a download that differs from the official one is pointed out.
  • Applies DXVK and the 4 GB patch safely, and notices when Steam's Verify integrity has undone them. The 4 GB patch is for copies without Steam's copy protection, such as GOG and EA App: Steam will not start its own executable once it is patched.
  • Diagnoses your install and suggests next steps, and backs up your saves.

It never downloads mods or game files, and never sends anything over the internet. Everything stays on your computer.

See it

Download

Windows 10 or 11, 64-bit, and Dragon Age: Origins (any edition). Nothing else to install.

Get it from the GitHub releases page or from Nexus Mods. Both are the same zip. Unzip it anywhere and run DAORework.exe.

Check your download

DAORework is not code-signed: a signing certificate would put the author's personal details on every download. So Windows SmartScreen may say it protected your PC. Choose More info, then Run anyway, after checking the zip one of these ways:

  1. Checksum: in PowerShell, run Get-FileHash DAORework-0.3.0-win-x64.zip and compare the hash with the one above and with the release's .sha256 file. This page is hosted separately from the downloads, so both have to agree.
  2. Build attestation: with the GitHub CLI, run gh attestation verify DAORework-0.3.0-win-x64.zip --repo arastella625/DAORework. It proves the zip was built by the project's own release workflow from its published source, and not changed since.

How it is built

DAORework is designed and directed by Amber Rastella, with an AI coding assistant writing much of the code under strict engineering standards, written decisions, automated tests and a run on a real install before every release. The whole story, in her own words: How DAORework is built.
