Roadmap

Where DAORework is going, and what 1.0 will mean.

No dates: each release ships when it's ready and checked on a real install.

What 1.0 will mean

Anyone, on any Windows copy of Dragon Age: Origins, can hand DAORework their whole setup and trust it without help. That comes down to four promises:

I

Tried by real players

Run on Steam, GOG and EA App copies, by players from outside the project, all the way through.

II

Installs what you use

Mods that run inside the game, such as DAO Lib and Luma, and add-ins that compete with each other.

III

Explains conflicts from the inside

Which lines of a game table two mods both change, not only that they share a file.

IV

Keeps its word

Your Library, profiles and History carry over to every later version, and you can hear about new ones if you want to.

The road

  1. 0.6.0Out now

    Help when something goes wrong

    • Find the problem mod turns half your mods off each round until one is left.
    • What changed shows what's new since your last game with other mods, with a way back.
    • Keep one of each clears the copies a library builds up, and conflicts say which could break quests.
  2. 0.6.xNext

    Fixes from real use

    • Whatever you run into with 0.6.0. Tell us on GitHub.
  3. 0.7.0Next

    Mods that run inside the game, and add-ins

    • Install DAO Lib, Luma and mods like them with the same preview and Undo as any other, once you've said yes to the program.
    • See which add-in wins when two ship the same file, and in what order the game loads them.
    • Move from Vortex brings over add-ins too.
  4. 0.8.0Planned

    Conflicts from the inside

    • When two mods change the same game table, see which lines each one changes.
    • The same for the game's text: dialogue and names two mods both rewrite.
    • Where it's safe, combine two tables whose changes don't overlap, so both mods work.
  5. 0.9.0Planned

    A guide, and the release candidate

    • A friendly guide to your first game with mods, from finding the game to pressing Play. Skip it, or open it again any time.
    • Everything works with the keyboard and with screen readers.
    • Your Library and profiles carry over to every later version.
    • If you choose to, hear about new versions. It stays off unless you say yes.
  6. 1.0The goal

    Ready for everyone

    • Released once players outside the project have run it on Steam, GOG and EA App copies, and no known bug can lose your mods, saves or game files.

After 1.0

  • Linux, through Steam's Proton. Sooner if a Linux player can try it on a real setup.
  • Mod Manager Download buttons on Nexus Mods, if Nexus agrees.
  • A music player for music you own, quiet while the game runs.
  • A look inside the game's files, for modders.
  • A helper you can ask about your own mods, in your own words, if you choose to turn it on. It goes online only when you ask it something, and every step it suggests is one you preview and can undo.

Plans can change. This page changes with each release.

Help it get there

DAORework has been tried on a real Steam copy. If you play the GOG or EA App copy, a few lines on how it went does more for 1.0 than anything else.
